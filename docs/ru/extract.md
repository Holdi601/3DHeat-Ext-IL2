# Построение уровней: `extract` {#building-levels-extract}

```text
heat3d-il2-level extract (<map> ... | --all) -o <folder> [--game FOLDER ...]
                 [--max-grid N] [--frame enu|game] [--origin LAT LON]
                 [--no-water] [--no-towns] [--skip-existing]
```

## Пошагово {#step-by-step}

Впервые в командной строке? Сначала прочитайте [С чего начать](before-you-start.md).

1. Найдите имя карты с помощью [`list`](list.md).
2. Выполните `heat3d-il2-level extract <map> -o levels`. В именах можно использовать подстановочные
   знаки, в кавычках (`"<family>_*"`); `--all` берёт каждую карту.
3. Чтобы положить запись на уровень без шага размещения, укажите её начало:
   `--origin <lat> <lon>`, равное `geo` записи (опорной точке её сессии). Без этого центр карты
   становится началом, а `geo` в `.json` показывает, какой именно.
4. Команда выводит строку на каждую карту по мере её декодирования, затем
   `ok <glb> <triangles> (<frame> frame)` или `failed <map>: <why>`.
5. Загрузите `<folder>/<map>/<map>.glb` в панель «Фон / уровень» просмотрщика.

## Параметры {#options}

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `maps` | - | имена карт, как их выводит `list`; допускаются подстановочные знаки |
| `--all` | выключен | каждая карта; сезоны, у которых общие карта высот и карта воды, записываются один раз |
| `-o`, `--out` | обязателен | папка вывода; каждая карта идёт в `<out>/<map>/` |
| `--game FOLDER` | находится сам | папка IL-2 (можно повторять) |
| `--max-grid N` | `1024` | не больше N отсчётов карты высот по стороне (1024: около 2 миллионов треугольников); карта берётся с шагом *k* отсчётов, чтобы уместиться |
| `--frame` `enu` или `game` | `enu` | `enu`: метры на восток, высота, метры на север от `--origin`, как таблицы Tacview у Watcher; `game`: собственные метры игры (x — север, y — высота игры, z — восток). Карта, которую нельзя разместить на Земле, пишется в `game`, что бы ни было запрошено |
| `--origin LAT LON` | центр карты | начало системы `enu` (`geo` записи) |
| `--no-water` | выключен | не брать воду |
| `--no-towns` | выключен | не брать контуры городов |
| `--skip-existing` | выключен | пропустить карты, у которых `.glb` уже есть |

Все параметры, как их выводит программа: [Справка по командам](../cli-reference.md).

Задайте `HEAT3D_DEBUG`, чтобы вывести полную трассировку ошибки для карты, которая не удалась.
Файл `.glb` пишется в `<map>.glb.part` и переименовывается, когда готов.

Код выхода: 0 — каждая карта записана; 1 — какая-либо не удалась (остальные всё равно
записаны); 2 — установка не найдена или ни одна карта не подошла.

## Примеры {#examples}

```bash
heat3d-il2-level extract <map> -o levels                         # одна карта, система enu вокруг её центра
heat3d-il2-level extract <map> --origin <lat> <lon> -o levels    # в плоской карте записи с таким geo
heat3d-il2-level extract "<family>_*" --max-grid 2048 -o levels  # точнее, несколько карт
heat3d-il2-level extract --all --skip-existing -o levels         # каждая карта, только новые
heat3d-il2-level extract <map> --frame game -o levels            # собственные метры игры, как их держат файлы миссий
```

Что находится в файлах: [Файлы уровней и системы координат](output.md).
