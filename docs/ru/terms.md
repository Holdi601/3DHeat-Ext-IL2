# Скорость, тесты, условия {#speed-tests-terms}

## Скорость {#speed}

Декодирование идёт на чистом Python, если не установлен numba (`python -m pip install -e .[fast]`):
карта средней величины занимает около 15 с без него и около секунды с ним; самая большая карта, несколько
сотен миллионов отсчётов, — около 7 с с ним (первый запуск также компилирует код). Память остаётся на
уровне одного ряда секторов плюс выходная сетка.

## Тесты {#tests}

```bash
python -m pytest -q
```

`tests/synth.py` строит в коде архивы, карты высот (кодировщик описанного выше кодека), файлы
`height.hini` и архивы без таблицы файлов.

## Условия {#the-terms}

Этот инструмент читает архивы вашей собственной установки IL-2 Sturmovik: Great Battles на вашем компьютере и никогда их не изменяет.

Ничего из игры не поставляется и не распространяется: ни файлов игры, ни кода игры, ни DLL; тесты сами создают каждый файл, который читают. Уровни, которые он записывает, остаются на вашем компьютере.

3DHeat IL-2 не связан с компанией 1C Game Studios / 777 Studios и не одобрен ею. IL-2 Sturmovik и связанные с ней названия и товарные знаки принадлежат их владельцам.

Правообладатели: откройте задачу на [github.com/Holdi601/3DHeat-Ext-IL2/issues](https://github.com/Holdi601/3DHeat-Ext-IL2/issues) - мы быстро отвечаем и по запросу удаляем что угодно.
