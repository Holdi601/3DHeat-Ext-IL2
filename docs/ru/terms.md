# Скорость, тесты, условия {#speed-tests-terms}

## Скорость {#speed}

Декодирование идёт на чистом Python, если не установлен numba (`python -m pip install -e .[fast]`):
карта средней величины занимает около 15 с без него и около секунды с ним; самая большая карта, несколько
сотен миллионов отсчётов, — около 7 с с ним (первый запуск также компилирует код). Память остаётся на
уровне одного ряда секторов плюс выходная сетка.

## Тесты {#tests}

```bash
python -m pytest -q
```

`tests/synth.py` строит в коде архивы, карты высот (кодировщик описанного выше кодека), файлы
`height.hini` и архивы без таблицы файлов.

## Условия {#the-terms}

Лицензионное соглашение IL-2 Sturmovik: Great Battles и IL-2 Series (1C Game Studios / 777 Studios)
**не найдено**: ни в установке (где `data/Licenses.txt` содержит только лицензии третьих сторон), ни
на сайте издателя, а страница Steam EULA не загрузилась. Проверьте его сами, прежде чем на это
полагаться. Этот инструмент только читает архивы и никогда их не меняет. Уровни, которые он пишет,
остаются на вашем компьютере: **никогда не публикуйте их**. Ничто здесь не поставляет данные игры,
а тесты строят каждый файл, который читают.
