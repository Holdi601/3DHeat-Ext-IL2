# Ταχύτητα, δοκιμές, όροι {#speed-tests-terms}

## Ταχύτητα {#speed}

Η αποκωδικοποίηση είναι σκέτη Python εκτός αν είναι εγκατεστημένο το numba (`python -m pip install -e .[fast]`):
ένας μεσαίου μεγέθους χάρτης παίρνει περίπου 15 s χωρίς αυτό και περίπου ένα δευτερόλεπτο με αυτό· ο
μεγαλύτερος χάρτης, αρκετές εκατοντάδες εκατομμύρια δείγματα, περίπου 7 s με αυτό (η πρώτη
εκτέλεση κάνει και μεταγλώττιση). Η μνήμη μένει σε μία σειρά τομέων συν το πλέγμα εξόδου.

## Δοκιμές {#tests}

```bash
python -m pytest -q
```

Το `tests/synth.py` φτιάχνει σε κώδικα archives, χάρτες υψομέτρων (έναν encoder για τον παραπάνω κωδεκ),
αρχεία `height.hini` και archives χωρίς πίνακα αρχείων.

## Οι όροι {#the-terms}

Η άδεια χρήσης του IL-2 Sturmovik: Great Battles και του IL-2 Series (1C Game
Studios / 777 Studios) **δεν βρέθηκε**: ούτε στην εγκατάσταση (της οποίας το
`data/Licenses.txt` περιέχει μόνο άδειες τρίτων), ούτε στον ιστότοπο του εκδότη,
και η σελίδα EULA του Steam δεν φορτώθηκε. Ελέγξτε το μόνοι σας πριν βασιστείτε σε αυτό.
Αυτό το εργαλείο μόνο διαβάζει τα archives και ποτέ δεν τα αλλάζει. Τα επίπεδα που γράφει μένουν
στον υπολογιστή σας: **μην τα δημοσιεύετε ποτέ**. Τίποτα εδώ δεν διανέμει δεδομένα παιχνιδιού, και οι
δοκιμές φτιάχνουν κάθε αρχείο που διαβάζουν.
