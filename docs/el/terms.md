# Ταχύτητα, δοκιμές, όροι {#speed-tests-terms}

## Ταχύτητα {#speed}

Η αποκωδικοποίηση είναι σκέτη Python εκτός αν είναι εγκατεστημένο το numba (`python -m pip install -e .[fast]`):
ένας μεσαίου μεγέθους χάρτης παίρνει περίπου 15 s χωρίς αυτό και περίπου ένα δευτερόλεπτο με αυτό· ο
μεγαλύτερος χάρτης, αρκετές εκατοντάδες εκατομμύρια δείγματα, περίπου 7 s με αυτό (η πρώτη
εκτέλεση κάνει και μεταγλώττιση). Η μνήμη μένει σε μία σειρά τομέων συν το πλέγμα εξόδου.

## Δοκιμές {#tests}

```bash
python -m pytest -q
```

Το `tests/synth.py` φτιάχνει σε κώδικα archives, χάρτες υψομέτρων (έναν encoder για τον παραπάνω κωδεκ),
αρχεία `height.hini` και archives χωρίς πίνακα αρχείων.

## Οι όροι {#the-terms}

Αυτό το εργαλείο διαβάζει τα αρχεία της δικής σας εγκατάστασης του IL-2 Sturmovik: Great Battles στον υπολογιστή σας και δεν τα αλλάζει ποτέ.

Τίποτα από το παιχνίδι δεν συνοδεύει το εργαλείο ούτε αναδιανέμεται: κανένα αρχείο του παιχνιδιού, κανένας κώδικας του παιχνιδιού, κανένα DLL· τα τεστ φτιάχνουν μόνα τους κάθε αρχείο που διαβάζουν. Τα επίπεδα που γράφει μένουν στον υπολογιστή σας.

Το 3DHeat IL-2 δεν συνδέεται με την 1C Game Studios / 777 Studios ούτε έχει την έγκρισή της. Το IL-2 Sturmovik και τα σχετικά ονόματα και εμπορικά σήματα ανήκουν στους κατόχους τους.

Δικαιούχοι: ανοίξτε ένα θέμα στο [github.com/Holdi601/3DHeat-Ext-IL2/issues](https://github.com/Holdi601/3DHeat-Ext-IL2/issues) - απαντάμε γρήγορα και αφαιρούμε οτιδήποτε κατόπιν αιτήματος.
