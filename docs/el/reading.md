# Πώς διαβάζονται τα αρχεία {#how-the-files-are-read}

| Μέρος | Κατάσταση |
|---|---|
| Archives (`data/*.gtp`, Great Battles) | ο πίνακας αρχείων (εγγραφές `S16R`, `STRMFAT?`, `DIR!`/`FILE`) και οι καταχωρίσεις (επικεφαλίδα `STRMFILE`, δεδομένα αποθηκευμένα ως έχουν)· κάθε `Maps*.gtp` της εγκατάστασης δοκιμών |
| `height.hini` | `height_map`, `water_map`, `heightMul`, `SeaLevel`, τα όρια παιχνιδιού και τα `MapNW/NE/SE/SW`· όλα στην εγκατάσταση δοκιμών |
| Χάρτες υψομέτρων (`height.dat`) | ο κωδικοποιητής παρακάτω· κάθε τομέας των χαρτών που αποκωδικοποιήθηκαν πλήρως κατά την εξερεύνηση χρησιμοποιεί ακριβώς το bitstream του (το πολύ το υπόλοιπο padding byte), τα υπόλοιπα ελέγχθηκαν από την επικεφαλίδα. Ελέγχθηκε bit προς bit με τα αρχεία `distlod.raw` χωρίς συμπίεση που το παιχνίδι στέλνει δίπλα στα `distlod.dat` του, και με τον χάρτη υψομέτρων μακρινού LOD ενός χάρτη (συσχέτιση 0,999) |
| Ύψη | μέτρα = raw x heightMul / 256 - SeaLevel x heightMul. Η θάλασσα ενός χάρτη αποκωδικοποιείται ακριβώς στο ύψος που δίνουν τα σχόλια του hini του· το περιθώριο ενός άλλου στο `bounds_level` του |
| Τοποθέτηση | διγραμμική παρεμβολή μεταξύ των τεσσάρων γωνιών του hini, γραμμή 0 βορράς, στήλη 0 δύση. Ελέγχθηκε σε έναν χάρτη με γνωστές πόλεις, ακτές και θάλασσες (ύψη πόλεων μέσα σε περίπου 10 m από τα πραγματικά, οι θάλασσες κάτω από τη στάθμη της θάλασσας). Οι γωνίες είναι τετράπλευρο, όχι η δική του προβολή του παιχνιδιού, οπότε περιμένετε κάποιες εκατοντάδες μέτρων σφάλμα στο μέσο ενός μεγάλου χάρτη. Το hini μιας οικογένειας χαρτών φέρει τις γωνίες ενός άλλου χάρτη (καλύπτουν ένα κλάσμα του πραγματικού του μεγέθους)· αυτό εντοπίζεται, και αυτή η οικογένεια τοποθετείται αντί γι' αυτό με προσαρμογή οροσήμων: πόλεις και αεροδρόμια από τις βάσεις δεδομένων τοποθεσιών του ίδιου του παιχνιδιού (`*.ldfbin`) απέναντι στις πραγματικές θέσεις τους, rms μερικών χιλιομέτρων (πόλεις απέναντι στα αεροδρόμια που φέρουν το όνομά τους, και συντεταγμένες των πραγματικών τόπων με ακρίβεια περίπου ενός χιλιομέτρου)· το JSON απαριθμεί κάθε ορόσημο και το υπόλοιπό του |
| Μάσκα νερού (`water.wtr`: τέσσερα επίπεδα πυραμίδας από πλακίδια, κάθε πλακίδιο ένας πίνακας μπλοκ των 400 m, κάθε μπλοκ ξηρά, γεμάτο ή εν μέρει νερό με το σχήμα του σε bit stream) | το κοντέινερ διαβάζεται σε κάθε χάρτη (κανένα byte δεν περισσεύει στα αρχεία που αποκωδικοποιήθηκαν πλήρως)· το σχήμα μέσα σε ένα εν μέρει υδάτινο μπλοκ **δεν αποκωδικοποιείται**. Τα γεμάτα μπλοκ είναι νερό· στα εν μέρει υδάτινα μπλοκ ένα δείγμα είναι νερό εκεί όπου ο χάρτης νερού (`height_w.dat`, ίδιος κωδικοποιητής με τον χάρτη υψομέτρων) είναι πάνω από το έδαφος, ή, δίπλα σε λίμνη, εκεί όπου το έδαφος δεν είναι πιο ψηλά από τη λίμνη· τα μπλοκ ξηράς είναι στεγνά. Έτσι το έλος που μόνο ο χάρτης νερού αναφέρει δεν μπαίνει στο νερό. Τα ποτάμια πιο στενά από το πλέγμα εξόδου βγαίνουν σπασμένα σε κομμάτια |
| Ίχνη πόλεων (τα decal meshes που απαριθμεί το `textures.tini`: `towns.mesh`, `cities.mesh`, `city_*.mesh`, `roads_fields.mesh`, ...: πλακίδια 25,6 km από επίπεδα τρίγωνα με υφή) | διαβάζονται σε κάθε χάρτη· κρατιούνται οι έδρες των οποίων η υφή είναι πόλη, χωριό ή βιομηχανικό έδαφος. Ελέγχθηκαν με τις πραγματικές πόλεις σε λίγους χάρτες (μια πόλη και στις δύο όχθες ενός ποταμού, μια συμβολή). Είναι ίχνη: το παιχνίδι τοποθετεί τα κτίρια κατά την εκτέλεση, και τα αρχεία δεν περιέχουν κτίρια |
| Αεροδρόμια, γέφυρες, κτίρια | **δεν διαβάζονται**: τα αεροδρόμια είναι αντικείμενα αποστολών, τα κτίρια προέρχονται από την τοποθέτηση του ίδιου του παιχνιδιού |
| Δάση (`forest_map.wtr`) | τα μπλοκ του διαβάζονται με τον ίδιο τρόπο, αλλά σχεδόν κάθε μπλοκ είναι «εν μέρει δάσος», οπότε χωρίς το bit stream δεν υπάρχει χρήσιμη μάσκα δάσους· δεν σχεδιάζεται |
| Οι υφές του εδάφους | δεν διαβάζονται |

## Ο κωδικοποιητής του χάρτη υψομέτρων {#the-heightmap-codec}

Βγήκε μόνο από τα αρχεία δεδομένων· δεν διαβάστηκε ούτε αποσυναρμολογήθηκε κώδικας του παιχνιδιού.
Little-endian:

```text
u32 width, u32 height, u32 sectorsX, u32 sectorsY, u32 sectorSize, f32 cellSize
u32 offset[sectorsX * sectorsY]            from the start of the file, row-major, top row first
sector: u16 count (bytes that follow), u16 mode ((log2 sectorSize) << 4 | LW, LW = 4),
        then a bitstream read MSB first:
  PRE   2 * (log2(sectorSize) - 5) bits, always 0 so far
  LIT   the first sample: sign (1), n (LW bits), magnitude (n + 1 bits)
  then until the sector is full:
    0 LIT       next = previous + LIT
    1 RUN LIT   the previous sample repeats RUN times (k: 3 bits, m: k + 1 bits, RUN = m + 1),
                then (unless the sector is full) next = previous + LIT
  values are 16-bit: read them modulo 65536
```

Οι μερικοί τομείς στη δεξιά και στην κάτω άκρη συμπληρώνονται και κόβονται. Ο ίδιος
κωδικοποιητής ισχύει για τον χάρτη νερού και τον χάρτη υψομέτρων μακρινού LOD.

## Προσαρμογές οροσήμων {#landmark-fits}

Εκεί όπου οι γωνίες ενός χάρτη δεν μπορούν να χρησιμοποιηθούν, το `landmarks.py` προσαρμόζει έναν αφινικό χάρτη από τα
μέτρα του παιχνιδιού στη γη με ελάχιστα τετράγωνα: οι θέσεις στο παιχνίδι από τα δικά σας
αρχεία (τα μπλοκ `Airfield` των αποστολών, οι βάσεις δεδομένων τοποθεσιών της καριέρας), οι πραγματικές θέσεις
από πίνακες δημοσιευμένων συντεταγμένων των τόπων μέσα στον κώδικα. Το `georeference` του JSON φέρει τον πίνακα, την αρχή, κάθε ορόσημο με το υπόλοιπό του
και το rms.
