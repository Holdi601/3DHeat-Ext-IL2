# Како се читаат датотеките {#how-the-files-are-read}

| Дел | Статус |
|---|---|
| Архиви (`data/*.gtp`, Great Battles) | табелата со датотеки (`S16R`, `STRMFAT?`, записи `DIR!`/`FILE`) и ставките (заглавие `STRMFILE`, податоците складирани како што се); секој `Maps*.gtp` од тест-инсталацијата |
| `height.hini` | `height_map`, `water_map`, `heightMul`, `SeaLevel`, границите на играта и `MapNW/NE/SE/SW`; секој од тест-инсталацијата |
| Мапи на височини (`height.dat`) | кодекот подолу; секој сектор од мапите декодирани целосно додека се откриваше го користи својот битов тек точно (најмногу остатокот од бајтното дополнување), останатите проверени по заглавие. Проверено бит по бит наспроти нескомпримираните датотеки `distlod.raw` што играта ги испорачува покрај нивната `distlod.dat`, и наспроти сопствената мапа на височини за далечен LOD на една мапа (корелација 0,999) |
| Височини | метри = raw x heightMul / 256 - SeaLevel x heightMul. Морето на една мапа се декодира точно во височината што ја даваат коментарите на нејзиниот hini; границата на друга во нејзиниот `bounds_level` |
| Поставување | билинеарно меѓу четирите агли на hini, ред 0 север, колона 0 запад. Проверено на една мапа наспроти познати градови, брегови и мориња (височините на градовите во рамките на околу 10 m од вистинските, морињата под морското ниво). Аглите се четириаголник, не сопствената проекција на играта, па очекувајте неколку стотици метри грешка во средината на голема мапа. Hini на едно семејство мапи ги носи аглите на друга мапа (опфаќаат дел од нејзината вистинска големина); тоа се открива, а тоа семејство наместо тоа се поставува со прилагодување по знаменитости: градови и аеродроми од сопствените бази на локации на играта (`*.ldfbin`) наспроти нивните вистински позиции, rms од неколку километри (градови наспроти аеродромите именувани по нив, и координати на вистинските места до околу еден километар); JSON ја наведува секоја знаменитост и нејзиното отстапување |
| Маска на вода (`water.wtr`: четири нивоа на пирамида од плочки, секоја плочка табела од блокови од 400 m, секој блок копно, полн или делумно вода со неговиот облик во битов тек) | контејнерот се чита на секоја мапа (ниту еден бајт не останува на датотеките декодирани целосно); обликот внатре во делумно-воден блок **не е декодиран**. Полните блокови се вода; во делумно-водни блокови примерок е вода таму каде што мапата на вода (`height_w.dat`, ист кодек како мапата на височини) е над теренот, или, до езеро, таму каде што теренот не е повисок од езерото; блоковите со копно се суви. Тоа ја отстранува мочуришната површина што само мапата на вода ја пријавува како вода. Реките потесни од излезната мрежа излегуваат скршени на парчиња |
| Отпечатоци на градови (мрежите на декалите што ги наведува `textures.tini`: `towns.mesh`, `cities.mesh`, `city_*.mesh`, `roads_fields.mesh`, ...: плочки од 25,6 km со рамни текстурирани триаголници) | читани на секоја мапа; се задржуваат површините чија текстура е град, село или индустриски терен. Проверено наспроти вистински градови на неколку мапи (град на двата брега на река, влив). Тоа се отпечатоци: играта ги поставува зградите при извршување, а датотеките не содржат згради |
| Аеродроми, мостови, згради | **не се читаат**: аеродромите се објекти на мисии, зградите доаѓаат од сопственото поставување на играта |
| Шуми (`forest_map.wtr`) | нејзините блокови се читаат на ист начин, но речиси секој блок е „делумно шума“, па без битовиот тек нема употреблива маска на шума; не се црта |
| Текстурите на теренот | не се читаат |

## Кодекот на мапата на височини {#the-heightmap-codec}

Откриен само од податочните датотеки; не е читан ниту дисасемблиран код на играта.
Little-endian:

```text
u32 width, u32 height, u32 sectorsX, u32 sectorsY, u32 sectorSize, f32 cellSize
u32 offset[sectorsX * sectorsY]            from the start of the file, row-major, top row first
sector: u16 count (bytes that follow), u16 mode ((log2 sectorSize) << 4 | LW, LW = 4),
        then a bitstream read MSB first:
  PRE   2 * (log2(sectorSize) - 5) bits, always 0 so far
  LIT   the first sample: sign (1), n (LW bits), magnitude (n + 1 bits)
  then until the sector is full:
    0 LIT       next = previous + LIT
    1 RUN LIT   the previous sample repeats RUN times (k: 3 bits, m: k + 1 bits, RUN = m + 1),
                then (unless the sector is full) next = previous + LIT
  values are 16-bit: read them modulo 65536
```

Делумните сектори на десниот и долниот раб се дополнуваат и сечат. Истиот
кодек ја содржи мапата на вода и мапата на височини за далечен LOD.

## Прилагодувања по знаменитости {#landmark-fits}

Таму каде што аглите на мапата не можат да се користат, `landmarks.py` прилагодува афина мапа од
метрите на играта до земјата со најмали квадрати: позиции во играта од сопствените датотеки
на корисникот (блокови `Airfield` на мисии, базите на локации на кариерата), вистински позиции
од табели со објавените координати на местата во кодот. `georeference` во JSON ја носи матрицата, потеклото, секоја знаменитост со нејзиното отстапување
и rms.
