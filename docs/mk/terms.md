# Брзина, тестови, услови {#speed-tests-terms}

## Брзина {#speed}

Декодирањето е чист Python освен ако numba е инсталиран (`python -m pip install -e .[fast]`):
мапа со средна големина трае околу 15 s без него и околу една секунда со него; најголемата
мапа, неколку стотици милиони примероци, околу 7 s со него (првото
извршување и компајлира). Меморијата останува на еден ред од сектори плус излезната мрежа.

## Тестови {#tests}

```bash
python -m pytest -q
```

`tests/synth.py` гради архиви, мапи на височини (енкодер за горниот кодек),
датотеки `height.hini` и архиви без табела со датотеки во код.

## Условите {#the-terms}

Лиценцниот договор на IL-2 Sturmovik: Great Battles и IL-2 Series (1C Game
Studios / 777 Studios) **не беше пронајден**: не во инсталацијата (чија
`data/Licenses.txt` содржи само лиценци на трети страни), не на страницата на издавачот,
а страницата за EULA на Steam не се вчита. Проверете го сами пред да се потпрете на ова.
Оваа алатка само ги чита архивите и никогаш не ги менува. Нивоата што ги пишува остануваат
на вашата машина: **никогаш не ги објавувајте**. Тука не се испорачуваат податоци од играта, а
тестовите ја градат секоја датотека што ја читаат.
