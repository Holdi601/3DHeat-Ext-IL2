# Брзина, тестови, услови {#speed-tests-terms}

## Брзина {#speed}

Декодирањето е чист Python освен ако numba е инсталиран (`python -m pip install -e .[fast]`):
мапа со средна големина трае околу 15 s без него и околу една секунда со него; најголемата
мапа, неколку стотици милиони примероци, околу 7 s со него (првото
извршување и компајлира). Меморијата останува на еден ред од сектори плус излезната мрежа.

## Тестови {#tests}

```bash
python -m pytest -q
```

`tests/synth.py` гради архиви, мапи на височини (енкодер за горниот кодек),
датотеки `height.hini` и архиви без табела со датотеки во код.

## Условите {#the-terms}

Оваа алатка ги чита архивите од твојата сопствена инсталација на IL-2 Sturmovik: Great Battles на твојот компјутер и никогаш не ги менува.

Ништо од играта не се испорачува ниту понатаму дистрибуира: ниту датотеки од играта, ниту код од играта, ниту DLL-датотеки; тестовите сами ја градат секоја датотека што ја читаат. Нивоата што ги запишува остануваат на твојата машина.

3DHeat IL-2 не е поврзан со 1C Game Studios / 777 Studios ниту е одобрен од нив. IL-2 Sturmovik и поврзаните имиња и заштитни знаци им припаѓаат на нивните сопственици.

Носители на права: отворете пријава на [github.com/Holdi601/3DHeat-Ext-IL2/issues](https://github.com/Holdi601/3DHeat-Ext-IL2/issues) - одговараме брзо и на барање отстрануваме што било.
