# ファイル表のないアーカイブを持つゲーム {#a-game-whose-archives-have-no-file-table}

IL-2 Series: Korea は、アーカイブに読めるファイル表を持ちません（名前は、各アーカイブの末尾のブロックでハッシュ化されています）。その設定ファイルも読める形では保存されていません。`list` は、そのマップをゲーム `Korea` として表示します。そのため:

- そのハイトマップと水のマップは、ヘッダーで見つけます（`height.dat` の形式。128サンプルのセクター。非常に大きな格子を細かいセルサイズで）。
- 地球上の位置は、ミッションが配置する飛行場（`data/Missions/**/*.Mission`。あなたのマシンで読みます）を、実際の飛行場の公表された座標（`korea.py`）に合わせる（フィッティングする）ことで決めます。残差は数十から数百メートルです。JSONには各目印とその残差が挙がります。
- heightMul と SeaLevel は推定です。ミッションの艦船は海の上にあるので、水のマップで最も多い（海の）値に対する艦船の高さから、尺度を求めます。高さは、もっともらしい値になります（海は海面より下、沿岸の町は数メートル）。それ以上の確認はしていません。JSONではこれらを推定と示しています。
