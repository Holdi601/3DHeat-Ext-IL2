# Скорост, тестове, условия {#speed-tests-terms}

## Скорост {#speed}

Декодирането е чист Python, освен ако не е инсталирана numba (`python -m pip install -e .[fast]`):
средно голяма карта отнема около 15 s без нея и около секунда с нея; най-голямата карта, няколко стотин милиона проби, около 7 s с нея (първото пускане също компилира). Паметта остава при един ред сектори плюс изходната мрежа.

## Тестове {#tests}

```bash
python -m pytest -q
```

`tests/synth.py` създава в кода архиви, височинни карти (кодер за кодека по-горе),
файлове `height.hini` и архиви без таблица с файлове.

## Условията {#the-terms}

Този инструмент чете архивите от собствената ви инсталация на IL-2 Sturmovik: Great Battles на вашия компютър и никога не ги променя.

Нищо от играта не се доставя и не се разпространява: никакви файлове на играта, никакъв код на играта, никакви DLL; тестовете сами изграждат всеки файл, който четат. Нивата, които записва, остават на вашата машина.

3DHeat IL-2 не е свързан с 1C Game Studios / 777 Studios и не е одобрен от тях. IL-2 Sturmovik и свързаните имена и търговски марки принадлежат на притежателите си.
