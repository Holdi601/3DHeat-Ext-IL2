# Скорост, тестове, условия {#speed-tests-terms}

## Скорост {#speed}

Декодирането е чист Python, освен ако не е инсталирана numba (`python -m pip install -e .[fast]`):
средно голяма карта отнема около 15 s без нея и около секунда с нея; най-голямата карта, няколко стотин милиона проби, около 7 s с нея (първото пускане също компилира). Паметта остава при един ред сектори плюс изходната мрежа.

## Тестове {#tests}

```bash
python -m pytest -q
```

`tests/synth.py` създава в кода архиви, височинни карти (кодер за кодека по-горе),
файлове `height.hini` и архиви без таблица с файлове.

## Условията {#the-terms}

Лицензионното споразумение на IL-2 Sturmovik: Great Battles и IL-2 Series (1C Game
Studios / 777 Studios) **не беше намерено**: нито в инсталацията (чийто
`data/Licenses.txt` съдържа само лицензи на трети страни), нито на сайта на издателя,
а страницата с EULA на Steam не се зареди. Проверете го сами, преди да разчитате на това.
Този инструмент само чете архивите и никога не ги променя. Нивата, които записва, остават
на вашата машина: **никога не ги публикувайте**. Нищо тук не доставя данни от играта, а
тестовете създават всеки файл, който четат.
