# Як чытаюцца файлы {#how-the-files-are-read}

| Частка | Стан |
|---|---|
| Архівы (`data/*.gtp`, Great Battles) | табліца файлаў (`S16R`, `STRMFAT?`, запісы `DIR!`/`FILE`) і запісы (загаловак `STRMFILE`, даныя захоўваюцца як ёсць); кожны `Maps*.gtp` тэставай усталёўкі |
| `height.hini` | `height_map`, `water_map`, `heightMul`, `SeaLevel`, межы гульні і `MapNW/NE/SE/SW`; кожны з тэставай усталёўкі |
| Карты вышынь (`height.dat`) | кодэк ніжэй; кожны сектар карт, расшыфраваных цалкам пры яго высвятленні, дакладна выкарыстоўвае свой бітавы паток (максімум астаецца запаўненне да байта), астатнія правераны па загалоўку. Правярана біт у біт па нестыснутых файлах `distlod.raw`, якія гульня пастаўляе побач з іх `distlod.dat`, і па ўласнай карце вышынь далёкага LOD карты (карэляцыя 0,999) |
| Вышыні | метры = raw x heightMul / 256 - SeaLevel x heightMul. Мора адной карты расшыфроўваецца роўна ў вышыню, якую даюць каментарыі яе hini; мяжа іншай — у яе `bounds_level` |
| Размяшчэнне | білінейна паміж чатырма вугламі hini, радок 0 поўнач, слупок 0 захад. Правярана на карце па вядомых гарадах, узбярэжжах і морах (вышыні гарадоў у межах каля 10 м ад сапраўдных, моры ніжэй за ўзровень мора). Вуглы — гэта чатырохвугольнік, а не ўласная праекцыя гульні, таму чакайце памылкі ў некалькі соцень метраў у сярэдзіне вялікай карты. Hini аднаго сямейства карт нясе вуглы іншай карты (яны ахопліваюць долю яе сапраўднага памеру); гэта выяўляецца, і гэтае сямейства змяшчаецца замест таго падгонкай па арыенцірах: гарады і аэрадромы з уласных баз даных месцаў гульні (`*.ldfbin`) супраць іх сапраўдных пазіцый, rms у пару кіламетраў (гарады супраць аэрадромаў, названых па іх, і каардынаты сапраўдных месцаў з дакладнасцю каля кіламетра); JSON пералічвае кожны арыенцір і яго нявязку |
| Маска вады (`water.wtr`: чатыры ўзроўні піраміды плітак, кожная пліта — табліца блокаў па 400 м, кожны блок — суша, поўны або часткова з вадой са сваёй формай у бітавым патоку) | кантэйнер чытаецца на кожнай карце (ні аднаго байта не засталося на файлах, расшыфраваных цалкам); форма ўнутры часткова воднага блока **не расшыфроўваецца**. Поўныя блокі — вада; у часткова воданых блоках адзнака — вада там, дзе карта вады (`height_w.dat`, той жа кодэк, што і карта вышынь) вышэй за зямлю, або, побач з возерам, дзе зямля не вышэй за возера; блокі сушы сухія. Гэта прыбірае балота, якое адна карта вады лічыць вадой. Рэкі, вузейшыя за выходную сетку, атрымліваюцца разбітымі на кавалкі |
| Контуры гарадоў (мешы-дэкалі, якія пералічвае `textures.tini`: `towns.mesh`, `cities.mesh`, `city_*.mesh`, `roads_fields.mesh`, ...: пліткі 25,6 км з плоскіх тэкстураваных трохвугольнікаў) | чытаюцца на кожнай карце; грані, чыя тэкстура — горад, вёска або прамысловая зямля, захоўваюцца. Правярана па сапраўдных гарадах на некалькіх картах (горад на абодвух берагах ракі, зліццё). Гэта контуры: гульня размяшчае будынкі падчас выканання, а ў файлах будынкаў няма |
| Аэрадромы, масты, будынкі | **не чытаюцца**: аэрадромы — гэта аб'екты місій, будынкі ідуць з уласнага размяшчэння гульні |
| Лясы (`forest_map.wtr`) | яго блокі чытаюцца гэтак жа, але амаль кожны блок «часткова лес», таму без бітавага патоку прыдатнай маскі лесу няма; не малюецца |
| Тэкстуры зямлі | не чытаюцца |

## Кодэк карты вышынь {#the-heightmap-codec}

Высветлены толькі з файлаў даных; ніякі код гульні не чытаўся і не дызасамблёўваўся.
Little-endian:

```text
u32 width, u32 height, u32 sectorsX, u32 sectorsY, u32 sectorSize, f32 cellSize
u32 offset[sectorsX * sectorsY]            from the start of the file, row-major, top row first
sector: u16 count (bytes that follow), u16 mode ((log2 sectorSize) << 4 | LW, LW = 4),
        then a bitstream read MSB first:
  PRE   2 * (log2(sectorSize) - 5) bits, always 0 so far
  LIT   the first sample: sign (1), n (LW bits), magnitude (n + 1 bits)
  then until the sector is full:
    0 LIT       next = previous + LIT
    1 RUN LIT   the previous sample repeats RUN times (k: 3 bits, m: k + 1 bits, RUN = m + 1),
                then (unless the sector is full) next = previous + LIT
  values are 16-bit: read them modulo 65536
```

Частковыя сектары на правым і ніжнім краях запаўняюцца і абрэзаюцца. Той жа
кодэк трымае карту вады і карту вышынь далёкага LOD.

## Падгонка па арыенцірах {#landmark-fits}

Дзе вуглы карты выкарыстаць нельга, `landmarks.py` падганяе афінную мадэль ад
метраў гульні да зямлі метадам найменшых квадратаў: пазіцыі гульні з уласных файлаў
карыстальніка (блокі `Airfield` місій, базы даных месцаў кар'еры), сапраўдныя пазіцыі
з табліц апублікаваных каардынат месцаў у кодзе. `georeference` у JSON нясе
матрыцу, пачатак, кожны арыенцір з яго нявязкай і rms.
