# Хуткасць, тэсты, умовы {#speed-tests-terms}

## Хуткасць {#speed}

Расшыфроўка — чысты Python, калі не ўсталяваны numba (`python -m pip install -e .[fast]`):
карта сярэдняга памеру займае каля 15 с без яе і каля секунды з ёю; самая
вялікая карта, некалькі соцень мільёнаў адзнак, каля 7 с з ёю (першы
запуск яшчэ і кампілюе). Памяць застаецца на ўзроўні аднаго рада сектараў плюс выхадная сетка.

## Тэсты {#tests}

```bash
python -m pytest -q
```

`tests/synth.py` будуе ў кодзе архівы, карты вышынь (кадавальнік для кодэка вышэй),
файлы `height.hini` і архівы без табліцы файлаў.

## Умовы {#the-terms}

Гэты інструмент чытае архівы вашай уласнай усталёўкі IL-2 Sturmovik: Great Battles на вашым камп'ютары і ніколі іх не мяняе.

Нічога з гульні не пастаўляецца і не распаўсюджваецца: ні файлаў гульні, ні кода гульні, ні DLL; тэсты самі ствараюць кожны файл, які чытаюць. Узроўні, якія ён запісвае, застаюцца на вашым камп'ютары.

3DHeat IL-2 не звязаны з кампаніяй 1C Game Studios / 777 Studios і не ўхвалены ёю. IL-2 Sturmovik і звязаныя з ёй назвы і гандлёвыя маркі належаць іх уладальнікам.

Праваўладальнікі: адкрыйце задачу на [github.com/Holdi601/3DHeat-Ext-IL2/issues](https://github.com/Holdi601/3DHeat-Ext-IL2/issues) - мы хутка адказваем і на просьбу прыбіраем што заўгодна.
