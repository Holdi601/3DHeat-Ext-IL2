# Побудова рівнів: `extract` {#building-levels-extract}

```text
heat3d-il2-level extract (<map> ... | --all) -o <folder> [--game FOLDER ...]
                 [--max-grid N] [--frame enu|game] [--origin LAT LON]
                 [--no-water] [--no-towns] [--skip-existing]
```

## Крок за кроком {#step-by-step}

Ви лише починаєте працювати з командним рядком? Спершу прочитайте [Перш ніж почати](before-you-start.md).

1. Знайдіть назву карти за допомогою [`list`](list.md).
2. Виконайте `heat3d-il2-level extract <map> -o levels`. У назвах можна використовувати
   маски в лапках (`"<family>_*"`); `--all` бере кожну карту.
3. Щоб покласти запис на рівень без жодного кроку розміщення, вкажіть його початок:
   `--origin <lat> <lon>`, встановивши значення `geo` запису (його опорну точку сесії).
   Без цього параметра початком стає центр карти, а `geo` у `.json` каже, яка саме.
4. Команда виводить рядок на кожну карту, коли її декодує, потім
   `ok <glb> <triangles> (<frame> frame)` або `failed <map>: <why>`.
5. Завантажте `<folder>/<map>/<map>.glb` у панелі «Тло / рівень» переглядача.

## Параметри {#options}

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| `maps` | - | назви карт, як їх виводить `list`; маски дозволено |
| `--all` | вимкнено | кожна карта; сезони, які мають спільні карту висот і карту води, записуються один раз |
| `-o`, `--out` | обов'язковий | папка виводу; кожна карта йде в `<out>/<map>/` |
| `--game FOLDER` | знаходиться | папка IL-2 (можна повторювати) |
| `--max-grid N` | `1024` | не більше N відліків карти висот з кожного боку (1024: близько 2 мільйонів трикутників); карта береться з кроком *k* відліків, щоб вміститися |
| `--frame` `enu` або `game` | `enu` | `enu`: метри на схід, висота і північ від `--origin`, як таблиці Tacview у Watcher; `game`: власні метри гри (x — північ, y — вгору, z — схід). Карта, яку неможливо розмістити на Землі, записується в `game` незалежно від запиту |
| `--origin LAT LON` | центр карти | початок системи `enu` (`geo` запису) |
| `--no-water` | вимкнено | не включати воду |
| `--no-towns` | вимкнено | не включати контури міст |
| `--skip-existing` | вимкнено | пропускати карти, для яких `.glb` уже існує |

Кожен параметр так, як його виводить програма: [Довідка з команд](../cli-reference.md).

Щоб побачити повний трасувальник помилки для карти, що не вдалася, встановіть
`HEAT3D_DEBUG`. Файл `.glb` записується в `<map>.glb.part` і перейменовується, коли
готовий.

Код виходу: 0 — кожну карту записано; 1 — якась не вдалася (інші все одно записані);
2 — інсталяцію не знайдено або жодна карта не підійшла.

## Приклади {#examples}

```bash
heat3d-il2-level extract <map> -o levels                         # одна карта, система enu навколо її центру
heat3d-il2-level extract <map> --origin <lat> <lon> -o levels    # на плоскій карті запису з таким geo
heat3d-il2-level extract "<family>_*" --max-grid 2048 -o levels  # точніше, кілька карт
heat3d-il2-level extract --all --skip-existing -o levels         # кожна карта, лише нові
heat3d-il2-level extract <map> --frame game -o levels            # власні метри гри, як їх мають файли місій
```

Що є у файлах: [Файли рівня і системи координат](output.md).
