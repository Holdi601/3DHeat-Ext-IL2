# Швидкість, тести, умови {#speed-tests-terms}

## Швидкість {#speed}

Декодування — чистий Python, якщо не встановлено numba (`python -m pip install -e .[fast]`):
середня карта займає близько 15 с без неї і близько секунди з нею; найбільша карта, кілька
сотень мільйонів відліків, — близько 7 с з нею (перший запуск також компілює). Пам'ять
лишається на одному рядку секторів плюс вихідна сітка.

## Тести {#tests}

```bash
python -m pytest -q
```

`tests/synth.py` будує в коді архіви, карти висот (кодер для описаного вище кодека),
файли `height.hini` і архіви без таблиці файлів.

## Умови {#the-terms}

Цей інструмент читає архіви вашої власної інсталяції IL-2 Sturmovik: Great Battles на вашому комп'ютері й ніколи їх не змінює.

Нічого з гри не постачається і не поширюється: ні файлів гри, ні коду гри, ні DLL; тести самі створюють кожен файл, який читають. Рівні, які він записує, залишаються на вашому комп'ютері.
