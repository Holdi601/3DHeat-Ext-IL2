# Како се датотеке читају {#how-the-files-are-read}

| Део | Стање |
|---|---|
| Архиве (`data/*.gtp`, Great Battles) | табела датотека (записи `S16R`, `STRMFAT?`, `DIR!`/`FILE`) и уноси (заглавље `STRMFILE`, подаци сачувани онако како јесу); сваки `Maps*.gtp` тест инсталације |
| `height.hini` | `height_map`, `water_map`, `heightMul`, `SeaLevel`, границе игре и `MapNW/NE/SE/SW`; сваки од тест инсталације |
| Висинске мапе (`height.dat`) | кодек испод; сваки сектор мапа декодован у потпуности током рада на томе користи свој битни ток тачно (највише преостала бајтна допуна), остало је проверено по заглављу. Проверено битно тачно према несажетим `distlod.raw` датотекама које игра испоручује уз своје `distlod.dat`, и према сопственој даљинској LOD висинској мапи мапе (корелација 0,999) |
| Висине | метри = сирово x heightMul / 256 - SeaLevel x heightMul. Море мапе се декодује тачно у висину коју наводе коментари њеног hini-ја; граница друге мапе у њен `bounds_level` |
| Постављање | билинеарно између четири угла hini-ја, ред 0 север, колона 0 запад. Проверено на мапи према познатим градовима, обалама и морима (висине градова у границама око 10 m од правих, мора испод нивоа мора). Углови су четвороугао, а не игрина сопствена пројекција, па очекујте неколико стотина метара грешке у средини велике мапе. Hini једне породице мапа носи углове друге мапе (покривају део њене праве величине); ово се открива, па се та породица смешта уклапањем по орјентирима: градови и аеродроми из игриних сопствених база локација (`*.ldfbin`) према њиховим правим положајима, rms од неколико километара (градови према аеродромима који носе њихово име, а координате правих места до око једног километра); JSON наводи сваки орјентир и његово одступање |
| Маска воде (`water.wtr`: четири пирамидална нивоа плочица, свака плочица је табела блокова од 400 m, сваки блок је копно, пун или делимично воден са обликом у битном току) | контејнер се чита на свакој мапи (нема преосталог бајта на датотекама декодованим у потпуности); облик унутар делимично воденог блока **није декодован**. Пуни блокови су вода; у делимично воденим блоковима узорак је вода где је мапа воде (`height_w.dat`, исти кодек као висинска мапа) изнад тла, или, уз језеро, где тло није више од језера; копнени блокови су суви. Тако се уклања мочвара коју сама мапа воде пријављује као воду. Реке уже од излазне мреже излазе изломљене на комаде |
| Отисци градова (мреже декала које наводи `textures.tini`: `towns.mesh`, `cities.mesh`, `city_*.mesh`, `roads_fields.mesh`, ...: плочице од 25,6 km равних текстурираних троуглова) | читају се на свакој мапи; задржавају се стране чија је текстура град, село или индустријско тло. Проверено према правим градовима на неколико мапа (град на обе обале реке, ушће). То су отисци: игра поставља зграде у време рада, а датотеке не држе зграде |
| Аеродроми, мостови, зграде | **не читају се**: аеродроми су објекти мисија, зграде долазе из игриног сопственог постављања |
| Шуме (`forest_map.wtr`) | његови блокови се читају на исти начин, али скоро сваки блок је „делимично шума", па без битног тока нема употребљиве маске шуме; не црта се |
| Текстуре терена | не читају се |

## Кодек висинске мапе {#the-heightmap-codec}

Схваћен само из датотека са подацима; није прочитан нити дисасемблован код игре.
Little-endian:

```text
u32 width, u32 height, u32 sectorsX, u32 sectorsY, u32 sectorSize, f32 cellSize
u32 offset[sectorsX * sectorsY]            from the start of the file, row-major, top row first
sector: u16 count (bytes that follow), u16 mode ((log2 sectorSize) << 4 | LW, LW = 4),
        then a bitstream read MSB first:
  PRE   2 * (log2(sectorSize) - 5) bits, always 0 so far
  LIT   the first sample: sign (1), n (LW bits), magnitude (n + 1 bits)
  then until the sector is full:
    0 LIT       next = previous + LIT
    1 RUN LIT   the previous sample repeats RUN times (k: 3 bits, m: k + 1 bits, RUN = m + 1),
                then (unless the sector is full) next = previous + LIT
  values are 16-bit: read them modulo 65536
```

Делимични сектори на десном и доњем ивицама се допуњују и обрезују. Исти кодек
важи за мапу воде и за даљинску LOD висинску мапу.

## Уклапање по орјентирима {#landmark-fits}

Где се углови мапе не могу користити, `landmarks.py` уклапа афино пресликавање из
игриних метара у Земљу методом најмањих квадрата: игрини положаји из самих
корисникових датотека (блокови `Airfield` мисија, игричне базе локација), прави
положаји из табела објављених координата места у коду. `georeference` у JSON-у
носи матрицу, почетак, сваки орјентир с његовим одступањем и rms.
